# tools/

## crosswalk-legacy.json

上游 `Zippland/perler-beads` 使用过的色卡交叉表：一个 HEX 对应五个品牌的色号。
自本仓库改为消费 `vendor/pindou-color-data` 的 per-brand 独立色板后，它已不再参与运行时。

保留原因：开发期做跨品牌对照时的历史参考。

**已知缺陷，不要再基于它做任何决策：**

该表假设"同一 HEX 在各品牌表示同一个颜色"。实测该假设不成立——与各品牌实测色卡逐条比对后，
COCO 有 61% 的色值存在肉眼可辨偏差（RGB 距离 > 20），误差中位数 25.6，最大 152.1；
另有极端样本如盼盼 1 号在表中为纯白 `#FEFFFF`、实测为纯黑 `#000000`。
完整数据见 `outputs/项目决策记录.md` 的 D4 条目。
